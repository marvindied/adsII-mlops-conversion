🛒 Gutschein-Ausspielung Live-Test

Wann wird ein Gutschein ausgespielt?
Ein 10% Rabattcode wird nur angezeigt, wenn die Kaufwahrscheinlichkeit zwischen 20% und 80% liegt.
• Unter 20%: Nutzer hat kein Interesse.
• Über 80%: Nutzer kauft ohnehin (Margenschutz).
